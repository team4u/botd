## 术语

| 术语 | 含义 |
| --- | --- |
| Hub | 提供网页、账户、会话记录和任务调度的控制服务 |
| 节点 | 运行 Node Agent 的一台设备或一个容器 |
| Node Agent | 连接 Hub、调用模型、执行工具的节点守护进程 |
| Bot | 属于某个节点的智能体，拥有模型、角色、记忆和工作目录 |
| 子代理 | 通过 `--parent` 创建、隶属某主控 Bot 的子代理，共享主工作区，可被 `Agent` 工具并发调度 |
| 会话 | 用户与主控 Bot 讨论任务的单聊 |
| 主控 Bot | 会话中默认接话、调度子代理与子会话的 Bot |
| 子会话 | 通过委派或自动化触发器派生的独立任务会话，完成后向父会话回报 |
| 触发器 | 让会话按计划或事件自动开始的配置，支持 Cron 与 Webhook |
| 外部渠道 | 连接 Hub 与 Telegram、Slack、飞书等外部消息服务的通道 |
| 技能 | 以 `SKILL.md` 描述操作方法的资源 |
| 扩展 | 由 Pi SDK 加载的可执行代码资源 |
| 产物 | 通过 Hub 在会话和节点之间传递的文件 |

界面或协议中的 `BOT`、`bot` 和 `Bot` 均指智能体。`direct` 指单聊模式。
